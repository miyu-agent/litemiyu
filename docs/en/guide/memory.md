# Prompt, project instructions and memory

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

Besides what you say, LiteMiyu gives the AI three more things: the prompt you wrote, the instruction files in your project, and the memories the AI has kept. This page says where each lives and how to change it. None of the three applies in sessions with no features.

## Prompt

The prompt is a piece of text given to the model at the start of every session. It tells the AI who it is and how it should work. LiteMiyu's built-in prompt is a single sentence:

```text
You are a helpful software engineer.
```

To use your own, run `/config`, open the `General` page, select `Prompt` and press `Enter`. LiteMiyu opens `~/.config/litemiyu/prompt.md` in your editor (`$VISUAL`, `$EDITOR`); write it, save, and quit the editor. For example:

```markdown
You are a careful software engineer. Always reply in Chinese.
Before changing code, read the surrounding code and follow its conventions.
```

- When the entry shows `Built-in prompt`, the built-in sentence is used; when it shows `Custom prompt`, the content of `prompt.md` is used.
- If `prompt.md` is an empty file, no prompt is added at all and the entry shows `Empty (adds nothing)`.
- To go back to the built-in prompt, delete `~/.config/litemiyu/prompt.md`.
- Changes apply to sessions started afterwards; sessions that are already open stay as they are.

You can also skip the settings screen and edit the file with any editor.

## Project instructions: AGENTS.md

If your project's root directory has an `AGENTS.md`, LiteMiyu gives its content to the AI when a session starts. It is the place for rules specific to this project, such as how to run the tests, code style, and which directories to leave alone:

```markdown
# Notes for the AI

- Run the tests with `cargo test`; they must pass before committing.
- Write comments and commit messages in English.
- Do not change files under `vendor/`.
```

How the files are found:

- When the working directory is inside a git repository, the `AGENTS.md` at every level from the repository root down to the working directory is read. Levels closer to the working directory come later, so instructions in a subdirectory can add to those above.
- When the working directory is not in a git repository, only the working directory itself is checked.
- At a level that has no `AGENTS.md` but does have a `CLAUDE.md`, the `CLAUDE.md` is read.

After a file changes, the AI receives the new content on the next turn; there is no need to reopen the session.

## Memory

Memory is what the AI writes down for itself and can still see in later sessions, such as your habits, decisions you made, and pitfalls you ran into.

Memories are ordinary text files, all in one folder:

```text
~/.local/share/litemiyu/memory/
├── MEMORY.md             the index: one line per memory, saying what it is about
├── prefers-english.md    one file per memory
└── …
```

- At the start of every session, the AI sees the `MEMORY.md` index. When an entry looks relevant to the task at hand, it reads that memory's file.
- When the AI thinks something is worth remembering, it writes a new file and adds a line to the index. You can also tell it directly, for example `remember: commit messages in this project are written in English`.
- Memory has no dedicated commands. To view, change or delete memories, open the files in this folder with your editor; or have the AI do it, for example `delete the memory about commit messages`.

The index has size limits: a line shows at most 150 characters, and at most the first 300 lines are shown. When there are too many memories, the AI merges duplicates and deletes outdated ones before writing new ones.

> Memory applies to every session and every project, so it suits facts about you. Rules that concern only one project belong in that project's `AGENTS.md`.
