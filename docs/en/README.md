# LiteMiyu documentation

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

LiteMiyu is an agent harness that runs full-screen in your terminal: one process and one program file. You chat with an AI and have it read and write files, run commands, and start subagents to do work for you. It supports Linux, macOS and BSD.

If this is your first time, start with the [Quick start](guide/quickstart.md).

## Relation to Miyu

LiteMiyu is a trimmed-down descendant of [Miyu](https://github.com/miyu-agent/miyu). It does one thing, an agent in the terminal, in exchange for a tiny footprint and a very fast start. If you need a web interface, messaging-platform integrations, scheduled tasks that keep running after the window is closed, or native Windows, use Miyu.

> It is best to have two agents: when one breaks, you still have the other. When Miyu is in trouble, LiteMiyu's [rescue mode](guide/rescue.md) can help you fix it.
