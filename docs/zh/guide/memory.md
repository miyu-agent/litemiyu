# 提示词、项目说明和记忆

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

除了你说的话，LiteMiyu 还会把另外三样东西交给 AI：你写的提示词、项目里的说明文件，以及 AI 自己记下的记忆。这一页介绍它们各自放在哪、怎么修改。这三样在“无功能”的会话里都不生效。

## 提示词

提示词是每个会话开头交给模型的一段话，用来告诉 AI 它是谁、应该怎么做事。LiteMiyu 自带的提示词只有一句：

```text
You are a helpful software engineer.
```

如果想换成自己的提示词，运行 `/config`，进入 `通用` 页，选中 `提示词` 按 `Enter`。LiteMiyu 会用你的编辑器（`$VISUAL`、`$EDITOR`）打开 `~/.config/litemiyu/prompt.md`，写好保存、退出编辑器即可。例如：

```markdown
You are a careful software engineer. Always reply in Chinese.
Before changing code, read the surrounding code and follow its conventions.
```

- 这一项显示 `内置提示词` 时用的是自带的那一句，显示 `自定义提示词` 时用的是 `prompt.md` 的内容。
- 如果 `prompt.md` 是一个空文件，就不加任何提示词，这一项显示 `空（不添加任何内容）`。
- 想恢复自带的提示词，删除 `~/.config/litemiyu/prompt.md` 即可。
- 修改之后新开的会话才使用新的提示词，已经开着的会话不变。

也可以不通过设置界面，直接用任何编辑器修改这个文件。

## 项目说明：AGENTS.md

如果你的项目根目录里有一份 `AGENTS.md`，LiteMiyu 会在会话开始时把它的内容交给 AI。这个文件适合写这个项目特有的规矩，例如怎么运行测试、代码风格、哪些目录不要动：

```markdown
# 给 AI 的说明

- 测试用 `cargo test` 运行，提交之前必须通过。
- 注释和提交说明用中文写。
- 不要修改 `vendor/` 下面的文件。
```

找文件的规则：

- 工作目录在一个 git 仓库里时，从仓库的根目录到工作目录，每一层的 `AGENTS.md` 都会读取。离工作目录越近的越靠后，所以子目录里的说明可以补充上层的说明。
- 工作目录不在 git 仓库里时，只读取工作目录这一层的。
- 某一层没有 `AGENTS.md` 但是有 `CLAUDE.md` 时，读取 `CLAUDE.md`。

文件修改之后，AI 会在下一轮收到新的内容，不需要重开会话。

## 记忆

记忆是 AI 自己记下来、以后的会话里还能看到的东西，例如你的习惯、你做过的决定、踩过的坑。

记忆就是普通的文本文件，都放在一个文件夹里：

```text
~/.local/share/litemiyu/memory/
├── MEMORY.md             目录：每条记忆一行，写着这一条讲的是什么
├── prefers-chinese.md    一条记忆一个文件
└── …
```

- 每个会话开始时，AI 会看到 `MEMORY.md` 这份目录。它觉得哪一条和眼下的事情有关，再去读那一条的文件。
- AI 认为某件事值得记住时，会自己写一个新文件，并且在目录里加一行。你也可以直接告诉它，例如 `记住：这个项目的提交说明用中文写`。
- 记忆没有专门的命令。想查看、修改或者删除记忆，直接用编辑器打开这个文件夹里的文件就可以了；也可以让 AI 来做，例如 `把关于提交说明的那条记忆删掉`。

目录有长度限制：一行最多显示 150 个字符，最多显示前 300 行。记忆太多的时候，AI 会先合并重复的、删除过时的，再写新的。

> 记忆对所有会话、所有项目都生效，所以适合记关于你本人的事情。只和某个项目有关的规矩，写进那个项目的 `AGENTS.md` 更合适。
