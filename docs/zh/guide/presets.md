# 预设

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

预设决定一个会话可以使用哪些内置工具、MCP 服务和技能。如果你只想让 AI 运行命令，或者只想让它使用其中几个工具，可以自己定义一个预设。这一页介绍预设是什么、怎么选择、怎么新建和编辑，以及它在配置文件里的写法。

## 预设是什么

一个预设是一张带名字的开关名单，它管三样东西：

- 内置工具，一共 12 件，见[工具和权限](tools.md)；
- 你接入的 MCP 服务；
- 技能。

预设只负责开和关。它不能修改提示词，也不会增加新的功能。在一个预设里关掉的工具，它的说明文字也不会发给模型。

技能是 AI 用 `read` 工具读取的。如果一个预设关闭了 `read`，这个预设里的技能即使打开也不会提供给 AI。

LiteMiyu 自带两个预设，它们不能编辑，也不能删除：

| 界面上的名字 | 名字 | 说明 |
|---|---|---|
| `全部功能` | `full` | 全部工具、MCP 服务和技能都可以使用。没有另外设置时，新会话使用的就是它 |
| `无功能` | `bare` | AI 没有任何工具，LiteMiyu 也不向对话里加入任何内容，相当于直接和模型聊天 |

除此之外，你可以定义任意多个自己的预设。自己定义的预设只筛选工具、MCP 服务和技能，每个回合开始时加入对话的时间、工作目录、项目说明和记忆和“全部功能”时一样。

## 新会话使用哪个预设

- 直接运行 `litemiyu`，或者在界面里运行 `/new`，新会话使用**默认预设**。默认预设一开始是 `全部功能`。
- `litemiyu --preset <预设名>`：这一次启动的第一个会话使用指定的预设，不修改默认预设。`litemiyu --bare` 等同于 `litemiyu --preset bare`。
- `/new <预设名>`：用指定的预设新建一个会话，不修改默认预设。预设名可以按 `Tab` 补全。
- `litemiyu ask --preset <预设名>`：在脚本里使用指定的预设。

预设名写的是上表里的“名字”：自带的两个是 `full` 和 `bare`，自己定义的就是你起的名字。写了不存在的预设名时，LiteMiyu 会说明没有这个预设，不会新建会话。

侧边栏的会话信息里始终显示当前会话使用的预设，例如 `预设 全部功能`。

首页没有侧边栏，窗口窄于 120 列时也没有侧边栏。这时如果预设不是 `全部功能`，输入框下面那一行会在模型的后面写出预设名，例如 `deepseek-chat demo · cmd`；预设是 `全部功能` 时不显示。在首页上，这里写的是下一个新会话将要使用的预设。

## /preset：选择和管理预设

在输入框里运行 `/preset`，打开预设列表。自带的两个预设排在前面，自己定义的预设按名字排序。默认预设的行首有一个 `●`，名字后面会标注 `自带`、`默认`、`当前会话`。

| 按键 | 作用 |
|---|---|
| `↑` `↓`（Vim 模式下也可以用 `j` `k`） | 选择 |
| `Enter` | 把选中的预设设为默认预设，同时切换当前会话 |
| `s` | 只切换当前会话，不修改默认预设 |
| `e` | 编辑选中的预设。在自带的两个预设上按 `e`，是以它为基础新建一份 |
| `a` | 新建一个预设 |
| `d` | 删除选中的预设，需要再按一次 `d` 确认。自带的预设不能删除 |
| `Esc` | 关闭 |

用鼠标点击一行，等于选中它以后按 `Enter`。

`e` 和 `a` 打开的是配置界面 `预设` 页的表单，见下面的[新建和编辑预设](#新建和编辑预设)。在表单里按 `Esc` 会回到这个列表。

### 会话开始以后预设是固定的

会话发出第一个请求以后，它的预设就固定了，不能再更换。这是因为更换工具会让模型的缓存失效，之后的每一次请求都要重新计费。重新打开的旧会话也是固定的。

预设固定以后，`/preset` 列表的下方会有一行说明，按键的作用也有两处不同：

- `Enter` 只修改默认预设，它只影响以后新建的会话，当前会话不变；
- `s` 变成“用选中的预设新建一个会话”。

如果想让当前这件事换一个预设做，就用 `s` 或者 `/new <预设名>` 新建一个会话。

一个会话使用的是它开始时的那张名单。之后即使你修改或者删除了这个预设，已经开始的会话仍然使用原来的工具，退出以后用 `litemiyu -c`、`litemiyu -s` 或者 `/sessions` 重新打开也是一样。这时侧边栏会在预设名后面标注 `（已修改）` 或者 `（已删除）`。

AI 派出的子代理使用和主会话相同的预设。

## 新建和编辑预设

运行 `/config`，进入 `预设` 页；或者在 `/preset` 列表里按 `a`、`e`。

`预设` 页先显示预设的列表：

| 按键 | 作用 |
|---|---|
| `Enter` | 编辑选中的预设。在自带的两个预设上是以它为基础新建一份 |
| `a` | 新建一个预设，先填写名称 |
| `d` | 删除选中的预设，会先询问一次 |
| `空格` | 把选中的预设设为默认预设 |
| `Esc` | 返回 |

预设的名称最多 32 个字符，不能包含空格和句点，不能以 `-` 开头，也不能是 `full` 或 `bare`。名称可以使用中文。

进入一个预设以后是它的表单：

```text
  名称              只用命令
  其余项目          关  没有单独设置的项目使用这个开关，以后新增的 MCP 服务和技能也使用它

  内置工具
  read              关  读取、跟随其余项目
  write             关  写入、跟随其余项目
  edit              关  编辑、跟随其余项目
  shell             开  执行命令
  jobs              开  任务
  …

  MCP 服务
  files             关  跟随其余项目

  技能
  skill-creator     关  跟随其余项目
```

- 用 `↑` `↓` 选择一行，按 `Enter` 或者空格修改。每修改一项都会立即保存，不需要另外按保存。
- `名称` 一行按 `Enter` 可以改名。
- `其余项目` 是一个总开关：没有单独设置过的每一项都使用它，以后新接入的 MCP 服务、新增加的技能也使用它。
- 单独设置过的项目不再跟随 `其余项目`。在这样的一行上按 `d`，可以让它恢复为跟随 `其余项目`。

修改保存以后，对之后新建的会话生效，已经开始的会话不变。

### 例子：只开 shell 和 jobs

1. 运行 `/preset`，按 `a`，填写名称，例如 `cmd`，按 `Enter`。
2. 新建的预设一开始是全部关闭的。把光标移到 `shell`，按空格打开；再对 `jobs` 做一次。
3. 如果想反过来「全部打开，只关掉几项」，把光标移到 `其余项目`，按空格把它打开，再关掉不要的几项。
4. 按 `Esc` 回到预设列表。按 `s` 让当前会话使用它，或者按 `Enter` 把它设为默认预设。

也可以在 `全部功能` 上按 `e`：这样新建出来的预设一开始就是全部打开的，只需要关掉你不要的几项。

## 预设和 MCP 页、技能页的开关

`/config` 的 `MCP` 页和 `技能` 页上，每个服务、每个技能有一个开关，这是全局开关，对全部会话生效。预设里的开关只对使用这个预设的会话生效。

一个 MCP 服务或者技能要同时满足两个条件才可用：全局开关是打开的，并且会话的预设里它也是打开的。全局开关关闭的项目，即使在预设里打开也不可用，预设的表单会在这一项后面写明 `已在 MCP 页关闭，在预设里打开也不可用`。

## 在配置文件里写预设

预设保存在配置文件 `config.toml` 里（位置见[数据放在哪](data.md)），也可以直接编辑：

```toml
[sessions]
default = "cmd"              # 默认预设；不写时是 full

[presets.cmd]
unlisted = "off"             # 其余项目：on 是打开，off 是关闭

[presets.cmd.features]       # 单独设置的项目：编号 = true 或 false
shell = true
jobs = true
mcp-files = true
skill-notes = true
```

| 项 | 说明 |
|---|---|
| `[presets.<名称>]` | 一个预设一张表。名称里有中文或者其他特殊字符时要加引号，例如 `[presets."只用命令"]` |
| `unlisted` | `"on"` 或者 `"off"`，就是表单里的 `其余项目`。这一项必须写，没有这一项的表不算一个预设 |
| `[presets.<名称>.features]` | 单独设置的项目，一行一项 |

`features` 里编号的写法：

| 项目 | 编号 | 例子 |
|---|---|---|
| 内置工具 | 工具名 | `shell`、`read`、`schedule_wakeup` |
| MCP 服务 | `mcp-<服务名>` | `mcp-files` |
| 技能 | `skill-<技能名>` | `skill-notes` |

如果名单里写了已经不存在的工具、MCP 服务或者技能（例如这个 MCP 服务后来从配置里删除了），LiteMiyu 不会报错，这一项只是不起作用。预设的表单会把它们列在 `已经不存在的项目` 里，在上面按 `Enter` 可以把它从预设里移除。

如果默认预设指向的预设已经不存在，新会话会按 `全部功能` 打开，并在你发出第一句话以后提示 `以下内容无效，已忽略：配置项 sessions.default`。

## 应急模式

[应急模式](rescue.md)不读取配置，AI 的工具是固定的那几件，所以应急模式里没有 `/preset` 命令。`--preset` 和 `/new` 后面只能写自带的 `full` 和 `bare`，写自己定义的预设名时 LiteMiyu 会说明原因。
