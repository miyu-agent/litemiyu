# 预设

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

预设决定一个会话可以使用哪些内置工具、MCP 服务和技能。如果你只想让 AI 运行命令，或者只想让它使用其中几个工具，可以自己定义一个预设。这一页介绍预设是什么、怎么选择、怎么新建和编辑，以及它在配置文件里的写法。

## 预设是什么

一个预设是一张带名字的开关名单，它管三样东西：

- 内置工具，一共 12 件，见[工具和权限](tools.md)；
- 你接入的 MCP 服务；
- 技能。

预设只负责开和关。它不能修改提示词，也不会增加新的功能。在一个预设里关掉的工具，它的说明文字也不会发给模型。

技能是 AI 用 `read` 工具读取的。如果一个预设关闭了 `read`，这个预设里的技能即使打开也不会提供给 AI。

LiteMiyu 自带两个预设，它们不能编辑，也不能删除：

| 界面上的名字 | 名字 | 说明 |
|---|---|---|
| `全部功能` | `full` | 全部工具、MCP 服务和技能都可以使用。没有另外设置时，新会话使用的就是它 |
| `无功能` | `bare` | AI 没有任何工具，LiteMiyu 也不向对话里加入任何内容，相当于直接和模型聊天 |

除此之外，你可以定义任意多个自己的预设。自己定义的预设只筛选工具、MCP 服务和技能，每个回合开始时加入对话的时间、工作目录、项目说明和记忆和“全部功能”时一样。

## 新会话使用哪个预设

- 直接运行 `litemiyu`，或者在界面里运行 `/new`，新会话使用**默认预设**。默认预设一开始是 `全部功能`。
- `litemiyu --preset <预设名>`：这一次启动的第一个会话使用指定的预设，不修改默认预设。`litemiyu --bare` 等同于 `litemiyu --preset bare`。
- `/new <预设名>`：用指定的预设新建一个会话，不修改默认预设。预设名可以按 `Tab` 补全。
- `litemiyu ask --preset <预设名>`：在脚本里使用指定的预设。

预设名写的是上表里的“名字”：自带的两个是 `full` 和 `bare`，自己定义的就是你起的名字。写了不存在的预设名时，LiteMiyu 会说明没有这个预设，不会新建会话。

运行 `/status` 可以看到当前会话使用的预设；会话还没开始时，这里显示的是下一个新会话将要使用的预设。窗口有 120 列或更宽时，侧边栏的会话信息里也会显示预设，例如 `预设 全部功能`。

## /preset：选择和管理预设

在输入框里运行 `/preset`，打开预设列表。自带的两个预设排在前面，自己定义的预设按名字排序。默认预设的行首有一个 `●`，名字后面会标注 `自带`、`默认`、`当前会话`。

| 按键 | 作用 |
|---|---|
| `↑` `↓`（Vim 模式下也可以用 `j` `k`） | 选择 |
| `Enter` | 把选中的预设设为默认预设，同时切换当前会话 |
| `s` | 只切换当前会话，不修改默认预设 |
| `e` | 编辑选中的预设。在自带的两个预设上按 `e`，是以它为基础新建一份 |
| `a` | 新建一个预设 |
| `d` | 删除选中的预设，需要再按一次 `d` 确认。自带的预设不能删除 |
| `Esc` | 关闭 |

用鼠标点击一行，等于选中它以后按 `Enter`。

`e` 和 `a` 打开配置界面的 `预设` 页，并在上面打开这个预设的窗口，见下面的[新建和编辑预设](#新建和编辑预设)。在窗口里按 `Esc` 会回到这个列表。

### 会话开始以后预设是固定的

会话发出第一个请求以后，它的预设就固定了，不能再更换。这是因为更换工具会让模型的缓存失效，之后的每一次请求都要重新计费。重新打开的旧会话也是固定的。

预设固定以后，`/preset` 列表的下方会显示 `当前会话的预设已固定`，按键的作用也有两处不同：

- `Enter` 只修改默认预设，它只影响以后新建的会话，当前会话不变；
- `s` 变成“用选中的预设新建一个会话”。

如果想让当前这件事换一个预设做，就用 `s` 或者 `/new <预设名>` 新建一个会话。

一个会话使用的是它开始时的那张名单。之后即使你修改或者删除了这个预设，已经开始的会话仍然使用原来的工具，退出以后用 `litemiyu -c`、`litemiyu -s` 或者 `/sessions` 重新打开也是一样。这时 `/status` 和侧边栏会在预设名后面标注 `（已修改）` 或者 `（已删除）`。

AI 派出的子代理使用和主会话相同的预设。

## 新建和编辑预设

运行 `/config`，进入 `预设` 页；或者在 `/preset` 列表里按 `a`、`e`。

`预设` 页是预设的列表：

| 按键 | 作用 |
|---|---|
| `Enter` | 打开选中的预设的窗口。在自带的两个预设上是以它为基础新建一份 |
| `a` | 新建一个预设：先填写名称，建好以后打开它的窗口 |
| `d` | 删除选中的预设，会先询问一次 |
| `Esc` | 返回 |

默认预设在 `通用` 页的 `默认预设` 一项里设置。

预设的名称最多 32 个字符，不能包含空格和句点，不能以 `-` 开头，也不能是 `full` 或 `bare`。名称可以使用中文。

预设的窗口浮在列表上面。窗口的标题是预设的名称，右上角显示光标所在那一项的工具名；下面是名称和三组开关，窗口够宽时排成两列：

```text
  cmd                                          jobs

  名称  cmd

  内置工具  2/12      MCP 服务  0/0
  [ ] 读取            还没有 MCP 服务
  [ ] 写入
  [ ] 编辑            技能  0/0
  [*] 执行命令        还没有技能
  [*] 任务
  [ ] 提问
  …
```

`[*]` 是打开，`[ ]` 是关闭；组名后面是打开了几项、一共几项。

| 按键 | 作用 |
|---|---|
| `↑` `↓`（Vim 模式下也可以用 `j` `k`） | 在一列里上下移动。在一列的最上面再往上，回到 `名称` 一行 |
| `←` `→`（Vim 模式下也可以用 `h` `l`） | 换到另一列 |
| `空格`、`Tab`、`Enter` | 打开或关闭光标所在的一项 |
| `Ctrl+A` | 有关闭的项就全部打开，全部打开时全部关闭 |
| `Enter`（在 `名称` 一行） | 改名，直接在这一行里修改 |
| `d` | 删除这个预设，会先询问一次 |
| `Esc`、`q` | 关闭窗口 |

每修改一项都会立即保存，不需要另外按保存。保存以后对之后新建的会话生效，已经开始的会话不变。

新建的预设一开始全部打开。以后新接入的 MCP 服务、新增加的技能，在用 `Ctrl+A` 全部打开过的预设里是打开的，在全部关闭过再挑选的预设里是关闭的。

### 例子：只开 shell 和 jobs

1. 运行 `/preset`，按 `a`，填写名称，例如 `cmd`，按 `Enter`。
2. 新建的预设一开始全部打开。按 `Ctrl+A` 全部关闭。
3. 把光标移到 `执行命令`（右上角显示 `shell`），按空格打开；再对 `任务`（`jobs`）做一次。
4. 按 `Esc` 回到预设列表。按 `s` 让当前会话使用它，或者按 `Enter` 把它设为默认预设。

如果想要“全部打开，只关掉几项”，在第 2 步不按 `Ctrl+A`，直接关掉不要的几项。

## 预设和 MCP 页、技能页的开关

`/config` 的 `MCP` 页和 `技能` 页上，每个服务、每个技能有一个开关，这是全局开关，对全部会话生效。预设里的开关只对使用这个预设的会话生效。

一个 MCP 服务或者技能要同时满足两个条件才可用：全局开关是打开的，并且会话的预设里它也是打开的。全局开关关闭的项目，即使在预设里打开也不可用，预设的窗口会在这一项后面写明 `已在 MCP 页关闭` 或者 `已在技能页关闭`。

## 在配置文件里写预设

预设保存在配置文件 `config.toml` 里（位置见[数据放在哪](data.md)），也可以直接编辑：

```toml
[sessions]
default = "cmd"              # 默认预设；不写时是 full

[presets.cmd]
unlisted = "off"             # 下面没有写到的项目：on 是打开，off 是关闭

[presets.cmd.features]       # 单独写的项目：编号 = true 或 false
shell = true
jobs = true
mcp-files = true
skill-notes = true
```

| 项 | 说明 |
|---|---|
| `[presets.<名称>]` | 一个预设一张表。名称里有中文或者其他特殊字符时要加引号，例如 `[presets."只用命令"]` |
| `unlisted` | `"on"` 或者 `"off"`：`features` 里没有写到的项目，以及以后新接入的 MCP 服务、新增加的技能，打开还是关闭。这一项必须写，没有这一项的表不算一个预设。在窗口里按 `Ctrl+A` 全部打开写 `"on"`，全部关闭写 `"off"` |
| `[presets.<名称>.features]` | 单独写的项目，一行一项。在窗口里打开或关闭一项时写的就是这里 |

`features` 里编号的写法：

| 项目 | 编号 | 例子 |
|---|---|---|
| 内置工具 | 工具名 | `shell`、`read`、`schedule_wakeup` |
| MCP 服务 | `mcp-<服务名>` | `mcp-files` |
| 技能 | `skill-<技能名>` | `skill-notes` |

如果名单里写了已经不存在的工具、MCP 服务或者技能（例如这个 MCP 服务后来从配置里删除了），LiteMiyu 不会报错，这一项只是不起作用。预设的窗口把它们排在最后，后面写着 `已不存在，Enter 移除`，在上面按 `Enter` 或者空格可以把它从预设里移除。

如果默认预设指向的预设已经不存在，新会话会按 `全部功能` 打开，并在你发出第一句话以后提示 `以下内容无效，已忽略：配置项 sessions.default`。

## 应急模式

[应急模式](rescue.md)不读取配置，AI 的工具是固定的那几件，所以应急模式里没有 `/preset` 命令，`/status` 里也没有预设一行。`--preset` 和 `/new` 后面只能写自带的 `full` 和 `bare`，写自己定义的预设名时 LiteMiyu 会提示 `应急模式只能用 full 或 bare`。
